สื่อการสอนแบบโต้ตอบ (สไลด์ 16:9 + เลื่อนอ่านบนมือถือ) จัดทำโดย **KRUBENZ** · Facebook: Ratchanon Udomlap

- วิเคราะห์ข้อสอบ O-NET ม.3 ภาษาอังกฤษ ปีการศึกษา 2564–2568 ทีละข้อ จัดกลุ่มตาม 2 สาระ 5 มาตรฐาน
- เฉลยตรวจเทียบกับเฉลยของ สทศ. · คำอธิบายและคำแปลภาษาไทย · คีย์เวิร์ดหลักฐานในบทอ่าน
- ข้อฝึกแต่งใหม่ · บัตรคำศัพท์ + เกมจับคู่ · ห้องสอบจำลอง Digital Testing
- เครื่องมือครู: จับเวลา สุ่มเลขที่ วงล้อสุ่มชื่อ แข่งทีม ปากกา/เลเซอร์ ซูมจุด

## โครงสร้าง
เว็บไซต์แบบ static ไม่ต้อง build — `index.html` เป็นหน้าแรก ข้อมูลอยู่ในไฟล์ `.js` ภาพอยู่ใน `img/`

## Deploy บน Vercel
1. Push โฟลเดอร์นี้ขึ้น GitHub repository
2. Vercel → Add New → Project → Import repository นี้
3. Framework Preset: **Other** · Build Command: เว้นว่าง · Output Directory: เว้นว่าง (ใช้ root)
4. Deploy · จากนั้นเปิด **Analytics** ในแดชบอร์ดโปรเจกต์เพื่อดูจำนวนผู้เข้าชม
